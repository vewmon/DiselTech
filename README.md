ДизельТех

1. Инструкция по запуску

Для Windows и PyCharm

1. Откройте PyCharm.
2. Выберите File → Open и откройте папку проекта "DiselTech".
3. Откройте терминал PyCharm через вкладку Terminal.
4. Активируйте виртуальное окружение:

.\venv\Scripts\Activate.ps1

5. Если Kivy не установлен, выполните:

python -m pip install kivy

6. В дереве файлов PyCharm найдите "Хабаров и Холеков.py".
7. Нажмите на него правой кнопкой мыши и выберите Run 'Хабаров и Холеков'.

Приложение должно запуститься в отдельном окне.

Если папки "venv" нет, создайте виртуальное окружение:

python -m venv venv

Затем активируйте его и установите Kivy.

2. Описание приложения

ДизельТех — приложение на Python и Kivy для учёта оборудования и управления рабочими заявками.

3. Возможности

- Создание и просмотр заявок.
- Изменение статусов заявок.
- Указание места выполнения работ, техники и водителя.
- Контроль времени выполнения заявок.
- Учёт наработки оборудования.
- Сохранение данных между запусками приложения.

4. Требования

- Windows 10/11.
- Python.
- PyCharm или другой редактор Python.
- Библиотека Kivy.

5. Хранение данных

Приложение сохраняет заявки и информацию об оборудовании в файле "requests_data.json" в папке данных приложения, которую определяет Kivy через "self.user_data_dir".

При повторном запуске сохранённые данные загружаются автоматически.

Важно: не удаляйте файл данных, если хотите сохранить информацию. При удалении приложения на Android локальные данные также могут быть удалены.

6. Сборка для Android

Сборка APK пока не настроена. В дальнейшем планируется использовать Buildozer и WSL с Ubuntu.

7. Статус проекта

Проект находится в разработке. Синхронизация данных между устройствами и push-уведомления требуют дополнительной настройки.
